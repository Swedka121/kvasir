# @org/ui

This library was generated with [Nx](https://nx.dev).

## Shadcn components

The package is configured by `components.json`. Add components from the workspace
root with:

```sh
npm exec -- shadcn add button --cwd packages/ui
```

Generated components live in `src/components/ui` and can be imported as
`@org/ui/components/ui/button`. Their theme styles are defined in the frontend
app's global stylesheet.

## Running unit tests

Run `nx test @org/ui` to execute the unit tests via [Jest](https://jestjs.io).
